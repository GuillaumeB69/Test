# TaskFlow Pro

Mini-produit front-end pour la gestion des tâches et le pilotage d'équipe.

## Fonctionnalités

- Thème dark/light avec toggle et persistance locale.
- Gestion du profil utilisateur et des membres d'équipe.
- Dashboard: KPIs, progression, alertes d'échéance, activité récente.
- Tâches: création, recherche, filtres avancés, Kanban drag & drop, commentaires.
- UX: raccourcis clavier, responsive, notifications toast.

## Utilisation

Ouvrez simplement `index.html` dans un navigateur moderne.

### Raccourcis clavier

- `/` : focus sur la recherche de tâches
- `n` : focus sur création d'une tâche
- `t` : toggle du thème
